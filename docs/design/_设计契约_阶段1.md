# 阶段1 试点闭环 · 详细设计共享契约

> 本文件是所有阶段1 详细设计子任务的共享输入：全局约束、接口数据结构、指标口径、技术栈、文档结构要求。
> 每个设计切片必须与本契约一致；跨切片接口引用同一字段名，不得另起炉灶。

## 1. 阶段1 范围与目标

- 周期：3 个月；范围：单平台 × 单品类（食品或美妆） × 试点区县。
- 目标：跑通"监测—识别—固证—分派—处置"人机协同闭环，验收指标见第 4 节。
- 架构：五层（L1 数据 / L2 执行双通道 / L3 本体 / L4 技能 / L5 应用）。执行层分"全量监测通道（无头拉流+ASR/OCR+规则/AI）"与"深度巡检通道（UI-TARS-desktop，阶段2 引入，阶段1 仅预留接口）"。

## 2. Global Constraints（与实施计划一致，设计必须遵守）

1. 法规引用一律以官方原文为准（阶段0 已归档《直播电商监督管理办法》全文，`docs/regulatory/直播电商监督管理办法全文.md`）。
2. 数据合规红线：平台协查为主通道；不绕过登录/验证码采集非公开数据；不采集与监管无关的个人信息；主播声音/人脸仅特征化使用，不留存可还原生物特征数据；全部采集行为入审计日志。
3. 处置权归位：系统与 AI 不直接作出任何对外处置；红级线索必须 2 名执法人员复核确认后方可进入处置程序；平台侧动作（下架/封禁/限流）仅通过协查/约谈机制要求平台落实。
4. 固证合规：每个固证包必须含 SHA-256 哈希与可信时间戳，取证设备专用且环境清洁。
5. 部署合规：核心系统本地化部署于政务内网/专网，数据不出域；不采用公有云 SaaS 承载监管数据。
6. 试点先行：阶段1 仅限单平台×单品类×试点区县，验收达标前不扩大范围。
7. 指标口径：以第 4 节定义为准。
8. 交付物语言：简体中文；法规条款原文不得改写。

## 4. 指标口径（方案 v2 第十二章）

- 监测覆盖率 = 实际监测直播间数 / 试点范围内可识别直播间总数（目标 ≥80%）。
- 识别精确率 = 系统判定违规且复核属实 / 系统判定违规总数（目标 ≥85%）。
- 识别召回率 = 系统发现的属实违规 / 抽样评估的属实违规总数（目标 ≥80%）。
- F1 = 精确率与召回率调和平均（目标 ≥0.82）。
- 人工复核率 = 需人工复核线索 / 系统命中线索（目标 ≤20%；红级 100% 复核）。
- 误判申诉率 = 经申诉成立纠错的线索 / 全部线索（目标 ≤1%）。
- 固证完整率 = 具备完整元数据+哈希+时间戳的固证包 / 应固证线索（目标 100%）。

## 5. 技术栈（建议，立项时确认）

- 流媒体拉流：FFmpeg（多路并发、断流重连、动态启停）。
- ASR：本地化中文转写引擎（Whisper 系，RTF<0.1，离线部署）；OCR：关键帧抽帧。
- 规则引擎：自研轻量规则服务（加载 `rules_v0.yaml`，规则优先、低延迟）。
- AI 识别：本地部署多模态模型，输出置信度 `ai_conf ∈ [0,1]`；低于 0.8 不直接产生黄级线索。
- 深度巡检：UI-TARS-desktop（阶段2 机群；阶段1 预留任务队列与白名单配置接口）。
- 部署：政务内网/专网本地化，等保 2.0 三级；数据库/对象存储本地。

## 6. 阶段1 双通道裁决规则（Task 1.3 必须遵守）

- 规则命中 → 生成红级线索（可回溯 `rule_ids`）。
- 规则未命中但 AI 判定违规且置信度 ≥0.8 → 生成黄级线索（必须人工初筛）。
- 其余 → 绿级归档。
- 红级线索 100% 双人复核；系统无自动对外处置出口。

## 7. 设计文档结构与写作要求

每个任务设计小节必须包含：
1. **任务目标与验收映射**：对应实施计划 Task 1.x 的验收标准。
2. **输入/输出接口**：引用第 3 节统一字段名。
3. **架构与模块划分**：模块职责、边界、目录结构（按实施计划 Files 约定）。
4. **关键流程/算法设计**：时序或状态机、规则匹配流程、异常与降级处理。
5. **数据结构与存储设计**：表/文档结构、索引、保留策略。
6. **安全与合规设计**：审计日志、脱敏、权限、等保要求映射。
7. **部署与运行设计**：进程/服务划分、配置、监控告警。
8. **风险与开放问题**：依赖、待定参数、需要业务方确认的事项。

要求：
- 简体中文；引用实施计划/方案 v2/法规原文时给出文件路径，不凭空编造。
- 跨任务只使用第 3 节接口字段；如需扩展字段，在本节字段上追加并标注"扩展"。
- 不写代码实现，只写设计；伪代码/JSON 示例可少量使用。
- 输出到指定切片文件，不修改其他切片文件。
