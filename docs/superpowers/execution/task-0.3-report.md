## 三、一致率计算方法与结果

**计算方法**：以样本为单位判定一致——`L1.is_violation == L2.is_violation` 且（违规时）`L1.rule_ids` 与 `L2.rule_ids` 集合相同；一致率 = 判定一致样本数 ÷ 样本总数。

**结果**：96/105 = **91.43%**，满足 ≥90% 的验收门槛。9 条分歧样本（SZDFD_0001、0003、0004、0025、0038、0058、0061、0071、0079）均已有 `arbiter` 记录定夺，仲裁结果作为金标准，仲裁记录 `agreed: true`。分歧样本的 L1/L2 原始判定保留（`agreed: false`），供事后分析。
