## 一、说明

### 1. 映射依据

- 依据《直播电商监督管理办法》（国家市场监督管理总局、国家互联网信息办公室令第117号，2026-02-01 施行版本）官方原文，即 `docs/regulatory/直播电商监督管理办法全文.md` 的「二、条款清单」与「三、全文」部分。
- 本表所有 `article_ref`（对应条号）均为该文档条款清单中实际存在的条号（第一条—第六十九条）；每条规则的 trigger 概念均取自对应条文原文，未凭记忆编造、未新增办法未规定的义务。

### 2. 适用范围

- 本表服务数字监管专员规则引擎 v0，覆盖《办法》中**可机器化**的禁令、义务、阈值类条款（以第二章平台义务、第三章直播间运营者与直播营销人员、第四章服务机构为主）。
- 第一章（总则）、第五章（监督管理机制）、第六章（法律责任）原则上不单独设规则：第五章为监管机制（作为触发背景），第六章罚则作为分级与处置参考，不产生新的义务。

### 3. 分级口径（level）

- **红**：规则触发即指向**直接危害消费者权益或严重违法行为**（虚假宣传、虚假功效宣称、售假、身份造假、AI 冒充真人、组织刷单等），触发后需**人工复核**。
- **黄**：合规义务/管理机制履行不到位或需关注的情形（信息展示缺失、核验记录缺失、制度建立不足、阈值异常提示等），需**关注并核实整改**。

### 4. 状态口径（status）

- `active`：参数齐备（法定时限、期限等均为固定值），可直接启用。
- `pending_params`：涉及业务方待定参数（重点对象规模阈值、投诉集中度阈值、价格波动/折扣幅度阈值），**禁止直接启用**，待 Task 0.2 Step 2 业务方定参后置为 active。

### 5. 未纳入 v0 的条款及原因（透明化记录）

| 条号 | 未纳入原因 |
| --- | --- |
| 第一条—第五条 | 总则/原则性条款，非可机器化义务 |
| 第六条、第七条 | 平台机制/规则制定类，属治理框架，暂不设独立触发规则 |
| 第十条 | 培训机制（记录核验可机器化但价值低，v1 视需要纳入） |
| 第十五条 | 信息变更核验 SLA（事件驱动、低频，v1 纳入） |
| 第二十一条、第二十二条、第二十三条 | 配合监管/失联提醒/处置善后，事件驱动、低频，v1 纳入 |
| 第二十四条 | 其他网络服务提供者兜底条款，非具体可机器化义务 |
| 第四十一条、第四十二条 | 服务机构培训/日常管理，与平台侧同类义务重复度高，v1 视需要纳入 |
| 第四十六条—第五十二条 | 监督管理机制（监管部门职责、管辖权、查处措施、信用监管、约谈） |
| 第五十三条—第六十七条 | 法律责任（罚则），作为分级与处置参考 |
| 第六十八条、第六十九条 | 附则（衔接适用、施行日期） |
